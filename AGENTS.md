# Physical device testing

- Never run `connected*AndroidTest` (or `connectedCheck`) directly against the default `com.neoruaa.meilox` application ID on a connected physical device: AGP uninstalls the target app after tests finish, wiping the user's local data and login session.
- Always pass an isolated application ID via Gradle property when running instrumented tests on a physical device, e.g. `-Pmei.applicationId=com.neoruaa.meilox.test`.
- On HyperOS physical devices, `connected*AndroidTest` / `am instrument` can stall with `ActivityTaskManager: Abort background activity starts` when Compose launches `ComponentActivity`. Instead of `connectedDebugAndroidTest`, build matched isolated APKs (`./gradlew -Pmei.applicationId=com.neoruaa.meilox.test :app:assembleDebug :app:assembleDebugAndroidTest`), install both (`-t` for test APK), run `adb shell am instrument ...`, and bring `com.neoruaa.meilox.test/androidx.activity.ComponentActivity` to the foreground with `adb shell am start -a android.intent.action.MAIN -c android.intent.category.LAUNCHER -f 0x10008000 -n com.neoruaa.meilox.test/androidx.activity.ComponentActivity` while instrumentation is running (or run on a headless AVD). Uninstall only `com.neoruaa.meilox.test` and `com.neoruaa.meilox.test.test` afterward.
- Never run `adb uninstall com.neoruaa.meilox` or `adb shell pm clear com.neoruaa.meilox` on a physical device unless explicitly requested by the user.
